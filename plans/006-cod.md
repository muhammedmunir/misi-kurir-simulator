## Mekanik

1. Di gudang, kira-kira 40% paket ialah COD, dengan jumlah RM10.00 hingga RM95.50 dalam gandaan 50 sen. Baris paket di Meja Sortir menunjukkan `· COD RM…`.
2. Pelanggan membayar dengan satu wang kertas: yang terkecil antara RM20, RM50 dan RM100 yang ≥ jumlah.
3. Panel Serah Terima menunjukkan `Status: COD RM…` dan "Pelanggan bayar RM…. Berapa baki?". Di bawahnya ada 3 butang baki.
   - Baki salah: mesej "Baki salah — kira semula", dan pemain boleh cuba lagi.
   - Baki betul: butang hilang, dan nota "COD diterima: RM…" dipaparkan.
4. "Serahkan paket" dikunci sehingga bukti diambil DAN COD dikutip.
5. Tunai COD **bukan** pendapatan kurir. Wang pemain bertambah dengan ganjaran sahaja. Tunai disetor semasa manifest ditutup, dan ringkasan menunjukkan baris "COD disetor".
6. COD yang gagal atau dipulangkan tidak dikira.

## Spesifikasi

### 1. `src/delivery/cod.ts` (baharu, fungsi tulen)

```ts
export function codNote(amount: number): number;            // 20 | 50 | 100: terkecil ≥ amount
export function codChange(amount: number): number;          // codNote − amount, dibundar ke sen
export function codChangeOptions(amount: number): number[]; // lihat di bawah
export function collectCod(session: DeliverySession, change: number, now: number): DeliverySession;
export function codCollectedTotal(cargo: readonly Packet[]): number; // Σ codAmount bagi delivered + cod
```

- `codChangeOptions`:
  - `k = Math.round(amount × 2) % 3`
  - `mula = max(0, baki − k)`
  - pilihan `[mula, mula + 1, mula + 2]`, dibundar ke sen
  - dengan cara ini jawapan betul tidak sentiasa di tengah.
- `collectCod`:
  - tiada handover, sudah dikutip, atau paket bukan COD → kembalikan `session` yang SAMA (rujukan sama);
  - baki salah → `interactionMessage = "Baki salah — kira semula"`;
  - baki betul → `handover.codCollected = true`, dan `interactionMessage = "COD diterima: " + formatRinggit(codAmount)`.
- Bundarkan ke sen (`Math.round(n × 100) / 100`) sebelum membanding.

### 2. Jenis (`src/types/delivery.ts`)

- `DeliveryHandover.codCollected?: boolean` (pilihan, supaya objek handover lama kekal sah).
